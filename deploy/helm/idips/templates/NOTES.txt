Important:
- Change the admin password after the first login.
- The admin credentials are only read when the database has no admin yet.
- DNS listens on port 53 inside the container. The chart grants NET_BIND_SERVICE
  and runs as root by default; change the IDIPS settings and this chart together
  if you want to use high ports.
- If you enable TLS for the admin listener in IDIPS, update the probes to use
  HTTPS or tcpSocket, otherwise readiness/liveness checks will fail.
- SQLite only supports one replica. Do not scale this Deployment.
- TPROXY needs hostNetwork, NET_ADMIN/NET_RAW and node-level nftables rules.
  Set tproxy.enabled=true and hostNetwork=true, then run
  scripts/nftables-tproxy.sh on the node.
